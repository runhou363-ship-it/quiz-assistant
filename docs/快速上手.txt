答题学习助手 v0.9.28 —— 快速上手
========================================

本项目不含任何 API Key，需要你自己填一个。

【第 1 步】用记事本打开 server\.env
          把 OPENAI_API_KEY= 后面填成你自己的 Key
          例：OPENAI_API_KEY=sk-xxxxxxxxxx
          等号后不要空格、不要引号。

【第 2 步】双击根目录的 start-server.bat
          看到 "Listen : http://127.0.0.1:8787" 即成功。
          这个黑色窗口请一直开着，做题时不要关。
          （首次运行会自动安装 Python 依赖，等几分钟）

【第 3 步】Chrome 打开 chrome://extensions
          右上角打开「开发者模式」
          点「加载已解压的扩展程序」
          选择本项目里的 extension 文件夹

【第 4 步】打开题目网页，右下角出现面板
          只看一题：点「查找答案」
          整理整份：勾选「自动模式」（自动翻页，不替你选、不提交）
          刷完一轮：自动模式会自己关闭，汇总保留，可先复制
          随时收工：点「查看汇总」，当场就关掉自动模式
          下一份：先复制上一轮汇总，再手动勾选「自动模式」
                  （开启时会清空上一轮，点错可「撤销清空」还原）
          只统计这一轮：点「重新抓取」，点一次就清空旧汇总并关闭
                        自动模式；点错可点「撤销清空」还原
          新开页面：跑完一轮后不会自己接着跑
          中途停了：断线/没识别出来属异常暂停，仍可续跑
          题型不准：用面板上的「题型」下拉手动选（含判断题）
          答案拿不准：点「夸克核对（复制本题）」，会复制好题目
                      并打开夸克，粘贴即可再查一遍
          题目显示乱码：说明加密字体没解出来，面板会提示
                      「解码失败」，此时请手动核对，不会硬答

【看视频（可选，不花钱）】打开课程目录页 → 点插件图标
          点「从当前页开始刷」：以当前选中的视频为起点，
          前面的不回头；当前这条已完成就从下一条开始
          播完一个自动跳下一个，按目录顺序往下
          默认 1 倍速（平台按真实时长计完成度，2x 只记一半）
          「作业 / 测验」一律跳过，题目你自己手动点
          已标 √ 的视频默认跳过，不会重刷
          播完会停留 12 秒等平台打勾；没打勾会在浮窗记下来
          若多数视频都不打勾：把「播完等待」改 30 秒再刷
          平台要刷新才显示 √：刷完点「刷新并核对完成」，
          只核对不继续刷；全刷完会自动停在「已完成」
          不用启动后端、不花 API 钱；浮窗可暂停/停止
          点不开就勾「平台加载慢」，会自动多等、换目标并重试
          播放器停在 0:00：会自动静音起播；也可手动点一下播放按钮
          点「开始」没反应：先在 chrome://extensions 刷新扩展，再点一次

【第 5 步】点「查看汇总」在窗口里看结果
          点「复制汇总文本」把内容取走
          （不会下载任何文件）

【速度与花费】默认一题约 1.3 秒、¥0.0024，一份 50 题作业约 ¥0.12
          面板会显示「用时 1.3s，¥0.0024」；重刷同一份作业命中缓存 0 元
          想更省：server\.env 里 QA_SAMPLES=1（约 ¥0.06 一份，但没有交叉验证）

----------------------------------------
检查配置：双击 check-config.bat，显示 has_key : True 即可
常见问题、配置说明、免费模型写法：见 docs\使用说明.md 和 server\.env.example
