# 使用说明（v0.9.26）

一个「浏览器扩展 + 本地后端」的刷题辅助工具：自动抓取题目 → 还原加密字体 → 查答案和解析 → **自动点「下一题」翻页** → 最后按题目顺序汇总给你。

> **它不会替你选任何选项，也不会提交试卷。** 答案只是整理出来供你思考后自己作答，仅限学习辅助。

## 二、准备（只需一次）

1. **浏览器**：Chrome / Edge 等 Chromium 内核浏览器。
2. **Python**：3.10 或 3.11，安装时勾选「Add Python to PATH」。启动脚本会自动检测并补装依赖。
3. **一个 API Key**：本工具通过 OpenAI 兼容接口调用大模型。推荐 DeepSeek（`https://platform.deepseek.com`）。也支持任何 OpenAI 兼容服务。
   - 想省钱可参考 `server/.env.example` 里的免费方案（智谱 GLM-4-Flash、硅基流动、本地 Ollama）。本地 Ollama 不需要 Key。

## 三、三步上手

### 第 1 步：填 API Key

用记事本打开 `server\.env`，找到：

```ini
OPENAI_API_KEY=
```

在等号后面粘贴你自己的 Key。**等号后不要有空格、不要加引号。**

### 第 2 步：启动后端

双击根目录的 **`start-server.bat`**。首次运行自动安装依赖（1–3 分钟）。看到这行即成功：

```
Listen : http://127.0.0.1:8787
```

> 这个黑色窗口要一直开着，关闭窗口 = 后端停止。
> 确认配置：双击 `check-config.bat`，`has_key : True` 即填好；或浏览器打开 `http://127.0.0.1:8787/status`。

### 第 3 步：安装扩展

1. Chrome 地址栏输入 `chrome://extensions` 回车；
2. 右上角打开 **开发者模式**；
3. 点 **加载已解压的扩展程序**；
4. 选中本包的 **`extension` 文件夹**（是文件夹，不是文件）；
5. 列表出现「答题学习助手 0.9.26」即完成。

以后改了代码，回这个页面点卡片上的 ↻，再刷新题目网页。

## 四、答题怎么用

打开题目页（已登录），右下角出现浮动面板。

| 想做的事 | 怎么操作 |
| --- | --- |
| 只看当前这一题 | 点「**查找答案**」，面板显示推荐选项、置信度和解析 |
| 自动整理整份作业 | 勾选「**自动模式**」：逐题查答案 → 只点「下一题」→ 跑完自动显示汇总 |
| 新开页面 / 新标签页 | 勾选状态会记住，会从当前题接着跑 |
| 手动翻了一题 | 面板自动跟随换题，自动模式下继续 |
| 中途停下来了 | 点「**重新抓取**」：重新识别当前题并接着翻页；当前题若已整理过，汇总从这道题重新开始 |
| 想从这一题重来 | 点「**重新抓取**」清空重来；点错了可点「**撤销清空**」还原 |
| 单选还是多选 | 自动识别；不准就用面板上的「**题型**」下拉手动指定（含判断题） |
| 查看整份结果 | 点「**查看汇总**」，在面板内显示，**不下载文件** |
| 把汇总拿走 | 点「**复制汇总文本**」，粘贴到任意地方 |
| 答案拿不准 | 点「**夸克核对（复制本题）**」：复制题干+选项并打开夸克 AI 搜索；低置信时结果区也会提示 |
| 想把视频连着看完 | 扩展弹窗点「**从当前页开始刷**」（详见下节，不需要后端） |

**自动模式的行为边界**：只点「下一题」，**不勾选选项、不提交**；网络抖动会退避重试并保留已整理进度；题目还没渲染时反复重试，抓不到就暂停而不是连跳两题。

**汇总按题目顺序排列**（第 1 题 → 第 N 题），每题带题型、推荐答案、置信度、分歧、你的选择和解析，开头有置信度概览与本次总花费。

## 五、自动看视频（不需要后端、不花钱）

弹窗主界面是：**一个「从当前页开始刷」按钮 + 停止 + 倍速 + 诊断目录**，其余设置收在折叠区。

### 行为

1. 只识别左侧目录里带「**视频**」标记的任务点并点开；
2. **必须真正播完**（播放器 `ended` / 进度到尾）才跳；播完停留 12 秒等平台记录，看到 ✓ 立刻跳下一个；
3. 按目录顺序依次往下，直到没有更多视频；顶部浮窗显示进度，随时暂停 / 停止。

### 「从当前页开始」是怎么判定的

启动时依次用三种线索定位目录里**当前选中的那条视频**：选中态 class → URL 的 `node_id` → 页面标题。把它**前面的全部标记为不回头**；如果当前这条已经被平台标成已完成，就从它的**下一条**开始。

三种线索都没有时，**从第一个未完成的视频开始**，并跳过前面已完成的（日志会写「已跳过前面 N 个已完成的视频」）。它不会靠「视口里第一条」猜——那样会永远回到开头重刷。

### 设置项（折叠区）

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 倍速 | **1x** | 多数平台按真实时长计完成度，2x 只记约一半 |
| 播完等待平台确认 | 12 秒 | 平台心跳慢可调到 30 |
| 连续 2 个没打勾时自动降到 1x | 开 | 兜底 |
| 单轮最多处理 | 100 | 到数一定停 |
| 跳过目录里已标完成的视频 | **开** | 避免重刷旧任务 |
| 单集最长等待 | 20 分钟 | 超时跳过并提示 |

### 边界（很重要）

作业、测验、考试、讨论、图文一律不点，题目你自己手动点；不点「提交 / 交卷 / 确定」，不替你选答案，不调用平台接口，不伪造学习时长；**不需要启动 `start-server.bat`，也不消耗 API Key**；页面刷新后不会自动恢复运行。

### 为什么「刷完了但平台没显示完成」

平台是否打勾由它自己的服务端决定，工具只能保证「真播完 + 给足上报时间」。常见原因：

| 原因 | 怎么办 |
| --- | --- |
| 平台按真实时长计时，2x 只记一半 | 把倍速改成 **1x** 重试 |
| 播完立刻切页，心跳丢了 | 把「播完等待」调到 30 秒 |
| 打勾要刷新页面才渲染 | 点弹窗的「**刷新并核对完成**」：只读核对，不会继续刷 |
| 工具没认出打勾样式 | 状态框会显示「⚠ N 个待复核」，按名字手动补看 |

工具**不会伪造心跳或学习时长**，只做「真播完 + 等待确认 + 明确告诉你哪些没被确认」。

### 排查

点「诊断目录」看识别到的「视频 / 跳过」标记；一个都没识别到说明目录结构特殊，把页面结构诊断发出来适配。点「开始」没反应时按顺序检查：① 版本号是否最新 → ② `chrome://extensions` 刷新扩展 → ③ 当前标签是不是课程目录页 → ④ 刷新页面重试。启动失败会直接在状态框写出原因。

## 六、关于题目文字乱码

雨课堂 / 学堂在线等平台用**加密字体**把题干显示成假字（DOM 里乱码、页面上正字）。本工具会自动：

1. 抓取页面字体文件，用字形比对还原真字；
2. **用同源参考字体比对**：加密字体内部是 `Source Han Sans SC VF`（思源黑体），包里自带对应的 `server/fonts/NotoSansSC-VF.ttf`。这是准确率的关键——早期用微软雅黑比对会反复把「学」认成「字」、「统」认成「绞」；换成同源字体后实测 5 份不同字体零错字、拟合分约 1.97（满分 2.0）；
3. 多尺寸融合（64 / 96 / 112）+ 低置信提示；
4. 点「查找答案」时让模型顺带校对明显不通顺的词，作为双保险，并把更正后的文字写回面板和汇总。

> **解不出来就不答。** 如果平均拟合分过低或超过 20% 的字没解出，工具会明确显示「解码失败，请手动核对」，**不会拿乱码去问模型**，自动模式也会暂停。

若 `/status` 的 `font_refs` 里没有 `sourcehan`，说明参考字体没加载，准确率会明显下降——确认 `server/fonts/NotoSansSC-VF.ttf` 存在并重启后端。仍有错字可直接在面板里手动修改题干/选项。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 面板提示「连不上后端」 | 后端窗口是否还开着？重启 `start-server.bat`；扩展会自动重试续跑 |
| `has_key : False` | `server\.env` 的 Key 没填，或有多余空格/引号，改完重启后端 |
| 面板根本没出现 | 刷新题目页 F5；确认扩展已启用、`chrome://extensions` 无报错 |
| 抓不到题干/选项 | 点面板「诊断结构」，把生成的 `server/debug/debug-*.json` 发出来适配 |
| 文字还原出现形近错字 | 打开 `/status` 看 `font_refs` 有没有 `sourcehan` |
| 自动模式停在某题不动 | 大概率是没识别成功（题干空/像目录/选项不足），面板会写原因；也可能是平台要求先选才能翻页 |
| 答案不对 | 工具不保证 100% 正确；把 `QA_SAMPLES` 调到 5，或换更强的模型 |
| 觉得慢 | 默认一题约 1.3 秒；`QA_SAMPLES=1` 可到 0.9 秒，代价是没有交叉验证 |
| 想更省钱 | 见第八节：`QA_SAMPLES=1` + `QA_VERIFY=0` 约省一半；同题缓存命中 0 元 |
| 想换模型 | 改 `.env` 的 `OPENAI_BASE_URL` / `OPENAI_MODEL` / `OPENAI_API_KEY` 后重启 |
| 首次打开有点慢 | 后端启动时后台预建字体位图缓存，首次解码约几秒，之后毫秒级 |

## 八、花多少钱（实测）

面板每答完一题会显示这题花费，例如「用时 1.3s，¥0.0024」；汇总概览里给本次总花费。

实测（2026-11-06，DeepSeek，5 道四选题受控 A/B）：

| 档位 | 模型调用 | 单题耗时 | 单题花费 | 50 题作业 |
| --- | --- | --- | --- | --- |
| 固定 3 采样（旧） | 3 次 | 1.82 s | ¥0.0043 | 约 ¥0.22 |
| **默认（自适应 2+N）** | 2 次 | **1.31 s** | **¥0.0024** | **约 ¥0.12** |
| 省钱档（`QA_SAMPLES=1`） | 1 次 | 约 0.9 s | 约 ¥0.0012 | 约 ¥0.06 |
| 同题缓存命中 | 0 次 | 0 s | ¥0 | ¥0 |

- 上表按「未命中缓存」算，属偏高估计，实际通常更低；
- 同一份作业刷新重刷会命中缓存，一分钱不花；
- 换 `.env.example` 里列出的免费模型或本地 Ollama，成本为 0。

## 九、配置项速查（`server/.env`）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 空 | **必填**（本地 Ollama 可留空） |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | 任何 OpenAI 兼容服务地址 |
| `OPENAI_MODEL` | `gpt-4o-mini` | 模型 ID |
| `QA_SAMPLES` | 2 | 每次最多采样次数（1–5），越多越稳也越贵 |
| `QA_ADAPTIVE` | 1 | 先跑 2 次，一致就省掉后续；设 0 退回固定跑满 |
| `QA_MAX_TOKENS` | 800 | 单次输出上限（输出最贵也最拖时间，不建议调大） |
| `QA_VERIFY` | 1 | 答案分歧时追加一次复核裁决 |
| `QA_CACHE` | 1 | 同题答案缓存，重复刷不再调用模型 |
| `QA_SEARCH` | off | 联网取证开关；国内中文搜索效果差，默认关闭 |
| `QA_SEARCH_TIMEOUT` | 4 | 搜索引擎超时秒数 |
| `QA_PRICE_IN` | 1.1 | 输入单价（元/百万 token），用于折算花费；免费模型填 0 |
| `QA_PRICE_OUT` | 4.3 | 输出单价（元/百万 token） |
| `QA_THINKING` | 未设 | 设 `0` 关闭思考模式。换 `deepseek-flash` 这类模型时必须设，否则一题 10s+ 且更贵 |

## 十、隐私与安全

- API Key 只保存在**你自己电脑**的 `server/.env`；项目里不含任何真实密钥，**不要把这个文件外传**。
- 题目文字发到**本机 127.0.0.1:8787**，再由后端发给你在 `.env` 里指定的模型服务商；不经其它第三方。
- 汇总副本静默写到本机 `server/reports/`，仅供「合并报告」使用，不下载、不外发。
- 字体解码、抓题、翻页、汇总展示全部在本机完成。
- 后端没有鉴权，**只监听 127.0.0.1，不要暴露到公网**。

---

## 十一、注意事项

- 仅供**学习辅助**，请自行思考后作答，不要用于正式考试作弊。
- 工具**不替你选选项、不提交**；自动模式只点「下一题」。
- 主观题、计算题、图片题抽取错误都会降低准确率；争议题会在汇总里标出分歧。
- 后端窗口关闭后扩展会重试，恢复后自动继续；导出汇总后进度清空，下次是全新一轮。
